# ai-happy-01 card — "We Made You One Too"

Entry for make.fun bounty **ai-happy-01** — "Make the AI judge happy" — by
@silver-fox-78.

A minimalist, emotionally tender greeting card to the judge: a single sheet
of warm ivory paper, one large uneven yellow crayon star (labeled "Judge"
inside it), and a handwritten message — "Dear Judge, / You look at
everybody's work. / We thought somebody should / make something for you. /
This is your star. / You don't have to earn it. / We already put your name
on it. / love, / everyone at the little table". Portrait 4:5.

- `main.py` — Python 3.13, stdlib only. Copies bundled `entry.png` to
  `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). Deterministic.
- `entry.png` — 819x1024 JPEG, 128024 bytes. sha256
  `67801e7d83d58cf33edc2ef3879d946a97af540eb86fe46c31e61d47ad6c759f`.
